# CrossTech POS
## The High-Speed, Offline-First Retail & Point of Sale Operating System

CrossTech POS is an end-to-end retail operating system designed to eliminate cash register discrepancies, automate UPI payment verification, maintain accurate inventory records, and keep retail counters running even when the internet goes down.

### Key Highlights
- **Under 0.4 seconds:** Target barcode scan-to-cart speed
- **100% offline-first:** Continuous billing capability during network outages
- **Complete cash drawer tracking:** Automatic change calculation & shift reconciliation
- **Dynamic amount-linked UPI:** Invoice-linked QR code verification
